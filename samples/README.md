# Sample CSV files

Upload these files in this order to demonstrate the full workflow:

1. `primary-loan-tape.csv` as **Primary loan tape**.
2. `servicer-update.csv` as **Servicer update**.
3. `document-manifest.csv` as **Document manifest**.

The primary tape deliberately includes validation issues. `expected-exceptions.csv` documents the expected baseline exceptions. `basic-validation-demo.csv` is a compact, legacy-header example for testing parser aliases and malformed values.
